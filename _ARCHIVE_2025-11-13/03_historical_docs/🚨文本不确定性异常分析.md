## 🔍 根因分析

### 原因1：CUDA OOM触发Fallback

从日志可见：
```
CUDA out of memory
warnings.warn(f"提取hidden states失败: {e}")
# 返回随机矩阵用于测试
return torch.randn(10, 768)
```

**问题链**：
1. GPU被全数据集实验占用（23.5GB/40GB）
2. `_get_text_hidden_states`失败（CUDA OOM）
3. 触发fallback，返回`torch.randn(10, 768)`
4. 随机矩阵计算的Gram matrix可能导致异常高的uncertainty

### 原因2：Normalization问题

代码中：
```python
max_entropy = torch.log(torch.tensor(len(eigenvalues), dtype=torch.float32))
uncertainty = (semantic_entropy / max_entropy).item()
```

**问题**：
- 如果`len(eigenvalues)`很小（比如只有10个token的随机矩阵）
- `max_entropy = log(10) ≈ 2.3`
- 如果`semantic_entropy`接近最大值，uncertainty会接近1.0

### 原因3：随机矩阵的eigenvalue分布

```python
# Fallback代码
return torch.randn(10, 768)  # [10, 768]

# Gram matrix
gram = hidden_states @ hidden_states.T  # [10, 10]

# 随机矩阵的Gram matrix的eigenvalues分布
# 可能非常不均匀，导致高熵
```
