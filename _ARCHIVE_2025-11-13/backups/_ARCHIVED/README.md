# 项目归档说明

本目录包含项目历史文件的归档，按日期组织。

## 📁 归档组织方式

文件按照**最后修改时间**自动分类到对应日期的文件夹中。

## 📂 目录结构

```
_ARCHIVED/
├── 2025-10-30/    # 最新归档（GitHub上传相关）
└── README.md      # 本说明文件
```

## 📋 归档内容类型

- **GitHub上传临时文件**: token、推送脚本、配置文档
- **构建日志**: 索引和语料库构建日志
- **临时脚本**: 各类Shell脚本
- **旧文档**: 已完成任务的相关文档

## 🗑️ 清理建议

如果磁盘空间不足，可以安全删除整个归档目录：

```bash
rm -rf /root/autodl-tmp/_ARCHIVED
```

或只删除特定日期的归档：

```bash
rm -rf /root/autodl-tmp/_ARCHIVED/2025-10-30
```

## 📌 注意事项

1. **归档文件不影响当前项目运行**
2. **所有敏感信息（如token）已失效**
3. **归档仅供历史参考，可随时删除**
