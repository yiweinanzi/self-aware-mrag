### P0-6: 阈值接口化

**目标**: 支持从外部注入阈值参数，为扫参做准备

**步骤**:

1. **修改不确定性估计器**: `flashrag/modules/uncertainty_estimator.py`
```python
class CrossModalUncertaintyEstimator:
    def __init__(self, config):
        # 从config读取阈值
        self.tau = config.get('uncertainty_threshold', 0.43)
    
    def should_retrieve(self, uncertainty, tau=None):
        """判断是否需要检索
        
        Args:
            uncertainty: 不确定性分数
            tau: 阈值（可选，如果不提供则使用默认值）
        
        Returns:
            bool: True表示需要检索
        """
        threshold = tau if tau is not None else self.tau
        
        # 记录到日志
        logger.debug(f"Uncertainty: {uncertainty:.4f}, Threshold: {threshold:.4f}")
        
        return uncertainty > threshold
```

2. **在pipeline中调用**
```python
# 支持从CLI注入阈值
if self.config.get('threshold_sweep_mode', False):
    tau = self.config['current_tau']
else:
    tau = None  # 使用默认值

should_retrieve = self.uncertainty_estimator.should_retrieve(u, tau=tau)
```

**验收标准**:
- 阈值可从 config/CLI 注入
- 日志中可见当前使用的阈值
- 为扫参实验做好准备
